# Каталог икон храма

Статическое веб-приложение для каталога икон и просмотра назначений на ближайшую неделю.

## Формат Google Таблицы

Опубликуйте лист как CSV и вставьте ссылку в поле приложения. Поддерживаются такие названия колонок:

- `Название` или `Икона`
- `Файл`, `Имя файла` или `Название файла`
- `Фото`, `URL`, `Ссылка`, `Cloudflare R2` или `image_url`
- `Новый стиль`, `new_style` или `Дата`
- `Старый стиль`, `old_style`
- `Место`
- `Теги`
- `Примечание`

Для неподвижных праздников можно писать `07.01`, `01-07` или `2026-01-07`. Для старого стиля приложение прибавляет 13 дней, что подходит для XX-XXI веков.

Для Cloudflare R2 используйте публичную прямую ссылку на файл, например:

```text
https://icons.example.com/thumbnails/kazanskaya.webp
```

Фото с Google Drive тоже поддерживаются: можно указывать обычную ссылку вида `https://drive.google.com/file/d/.../view`. Приложение преобразует ее в thumbnail-ссылку.

## Запуск

Откройте `index.html` в браузере.
